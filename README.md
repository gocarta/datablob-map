# datablob-map
Map for visualizing any geospatial datablob dataset.

<img width="265" height="234" alt="image" src="https://github.com/user-attachments/assets/75c12f9f-739d-4147-80e2-b48f6639a514" />

## features
- Simple configuration
- Easy to embed in an iframe

## usage
Set the URL param dataset_url to the url of your meta.json file.  Here's an example
```
https://gocarta.github.io/datablob-map/?dataset_url=https://gocarta.s3.us-east-2.amazonaws.com/public/data/bike_chattanooga_stations/v1/meta.json
```
